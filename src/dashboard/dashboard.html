Cleartweet

Deletes your tweets on X from your data archive.

01 Load your archive

Request your data at x.com/settings/download_your_data. X usually takes one or two days. When it arrives, drop the zip here, or the tweets.js file from its data folder.

Your archive is read inside this browser. Nothing is uploaded anywhere.

02 Choose what to delete

This file only lists tweet ids and dates, so filtering by type, words or likes is unavailable. Use tweets.js for the full set of filters.

Types

    Deleting

    Keep Chrome open. The X tab can stay in the background, and a closed browser picks up where it stopped.
